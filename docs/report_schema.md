# Report Schema

## Final report sections

1. Executive Summary
2. Structural Effects
3. Social Reactions
4. High-risk Groups / Regions
5. Acceptance / Backlash Outlook
6. Mitigation Recommendations
7. Confidence and Evidence

## Seoul-specific verdict schema

- 경제적 효과
- 생활 편익/불편
- 취약집단 영향
- 수용성
- 반발 위험
- 보완 정책

## Interaction after report

- Ask a specific agent why it reacted that way
- Ask a report agent for targeted follow-up summaries
